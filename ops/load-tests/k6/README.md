# Нагрузочные тесты (k6)

Цель — поймать регрессии по задержкам и ошибкам на горячих **GET** API витрины.

## Установка k6

- macOS: `brew install k6`
- Или Docker: см. официальную документацию Grafana k6

## Запуск против локального Docker

```bash
cd /path/to/Shoria
BASE_URL=http://localhost:8080 k6 run ops/load-tests/k6/catalog-core.js
```

Параметры окружения:

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `BASE_URL` | `http://localhost:8080` | Корень сайта (тот же хост, что и в браузере) |
| `VUS` | `10` | Виртуальные пользователи |
| `DURATION` | `45s` | Длительность сценария |

Пороги `p(95)` / `p(99)` заданы в скрипте — скорректируйте под целевой SLA и мощность стенда.

## Прод

Запускать только с явного разрешения и с учётом rate limit / мониторинга; предпочтительно копия продовых данных на staging.
